# Disputes

Version 1 has no dispute process.

No administrator, treasury controller, or seed operator can seize, transfer, burn, rewrite, or otherwise alter a name that is still active or inside its grace period. There is no court, trademark, or impersonation function in the contracts. A reserved label can be released only while it is unregistered. A lapsed name can be burned by anyone after grace, including the next registrant; that burn is permissionless cleanup, not an administrative seizure.

If a later version adds an exceptional dispute process, it has to be a new contract or an explicitly documented upgrade. It is not hidden in these contracts.
